# smart-cargo-shipping

Smart Cargo Shipping is an intelligent logistics platform for Egypt and MENA.

This repository contains the source code and assets for the Smart Cargo Shipping web application.

## Overview

- Ship smarter with carrier matching, live tracking, and carton-level booking.
- Designed for Egyptian merchants and logistics operators.
- Supports domestic and international shipping flows across the MENA region.
